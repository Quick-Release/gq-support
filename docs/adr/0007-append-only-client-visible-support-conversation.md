# The client-visible support conversation is append-only

The initial report is represented by the GitHub issue body and every later client or support message by a GitHub comment. MVP messages are append-only: corrections are new comments, GitHub `open`/`closed` is the authoritative support status, and only an allowlisted set of client-visible classifications is projected; internal engineering labels and discussion remain outside the support conversation. The GitHub App's provider identity is supplemented by verified WordPress reporter and installation attribution.
