# D1 databases are created in the EU jurisdiction

Every stage's D1 database is created with `jurisdiction: "eu"`. The jurisdiction cannot be changed after creation, and the Client base is mainly European. Choosing it now costs nothing, while moving later would mean a migration to a new database. This is not a compliance claim: Workers execute wherever the request lands, and the Project repository lives on GitHub, outside the EU. Data-location commitments to Clients must name all three.
