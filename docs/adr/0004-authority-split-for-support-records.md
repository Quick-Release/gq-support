# GitHub owns the conversation while operations own delivery state

WordPress remains authoritative for the local installation, environment, current user, and capabilities; the approved onboarding configuration owns client-to-repository routing; GitHub owns the support request, client-visible messages, support status, and client-visible labels; operational records own only routing references, idempotency, receipts, delivery attempts, and reconciliation state. The widget reads projections and never becomes a competing support database.
